# TxLINE Endpoints

Complete enumeration of every TxLINE surface Momentum touches — HTTP endpoints AND on-chain program instructions.

TxLINE's on-chain program is **`txoracle` v1.4.2** deployed on Solana devnet at:

```
6pW64gN1s2uqjHkn1unFeEjAwJkPGHoppGvS715wyP2J
```

Base HTTP host is configured via `TXLINE_BASE_URL` (devnet endpoint provided by the sponsor). All authenticated calls carry dual headers: `Authorization: Bearer <jwt>` and `X-Api-Token: <apiToken>`. `Accept-Encoding: identity` is set globally to sidestep Bun's zstd decompression bug on some TxLINE responses.

## Notes

- Auth is centralized in `backend/src/lib/txline/client.ts` — a shared axios instance with a request interceptor injecting both headers and a response interceptor that triggers exactly one `refresh()` + retry on HTTP 401.
- Refresh concurrency is coalesced in `backend/src/lib/txline/refresh.ts` so a burst of 401s does not fan out to N re-subscribe attempts.
- The `daily_scores_roots` PDA seeds are `[b"daily_scores_roots", u16_le(epoch_day)]` under the `txoracle` program. `epoch_day` is derived from `summary.updateStats.minTimestamp` (verified live on devnet PDA `FDU3RVD6u95iLNdVrTNpars2dM8XLyf1doNThPjY7ypm` for epoch_day 20648).
